# MindSight: AI-Powered Mental Health Risk Detection Through Conversational Analytics

## Overview
**MindSight** is an AI-driven natural language processing system designed to analyze conversational text (such as Reddit community discussions) to detect linguistic patterns and markers indicative of psychological distress and stress. By leveraging hybrid natural language processing techniques, transformer-based language representations, and explainable AI (XAI) frameworks like SHAP and LIME, MindSight provides interpretability behind flagged risks to support early screening workflows.

---

> [!WARNING]
> ### ⚠️ Ethical Disclaimer & Scope Limitation
> **MindSight is strictly an experimental screening and research aid, NOT a diagnostic medical tool.**  
> It does not provide medical diagnoses, treatment recommendations, or clinical psychological assessments. The predictions generated by this system must never replace professional consultation with qualified healthcare professionals or clinical psychologists. If you or someone you know is experiencing acute emotional distress or a mental health crisis, please reach out to local emergency services or national crisis helplines immediately.

## Setup & Installation

### 1. Prerequisites
- Python 3.10+ (Recommended: Python 3.10 or 3.11)
- [Git](https://git-scm.com/)

### 2. Create and Activate Virtual Environment (`venv`)
```bash
# Create virtual environment named .venv
python -m venv .venv

# Activate on Windows (PowerShell):
.venv\Scripts\Activate.ps1

# OR Activate on Windows (Command Prompt):
.venv\Scripts\activate.bat

# OR Activate on Linux / macOS:
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
# Upgrade pip to latest version
pip install --upgrade pip

# Install project requirements
pip install -r requirements.txt

# Download required NLTK data & spaCy language model
python -m spacy download en_core_web_sm
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('vader_lexicon')"
```

### 4. Initialize Data Version Control (DVC)
```bash
# Initialize DVC inside your git repository
dvc init

# Track data directories with DVC (keeps large files out of Git)
dvc add data/raw
dvc add data/processed

# Commit DVC tracking files to Git
git add data/raw.dvc data/processed.dvc .dvcignore
git commit -m "chore: initialize DVC and track data directories"
```

## Development Roadmap & Modules

1. **Data Pipeline (`src/data`)**: Ingestion of conversational Reddit text (e.g., Dreaddit / SMHD / SAD datasets), removal of noise, tokenization, anonymization.
2. **Feature Extraction (`src/features`)**: Lexical diversity, sentiment polarity scores (VADER), psycholinguistic markers, TF-IDF, and contextual transformer embeddings.
3. **Modeling (`src/models`)**: Classical baselines (Logistic Regression, Random Forest, XGBoost) and deep transformer models (RoBERTa / MentalBERT / DistilBERT).
4. **Explainability (`src/explainability`)**: SHAP value generation and LIME surrogate explanations for word/phrase-level feature attributions.
5. **Inference & UI (`src/api` & `src/app`)**: FastAPI REST endpoints for real-time risk scoring alongside an intuitive Streamlit analytical dashboard.
